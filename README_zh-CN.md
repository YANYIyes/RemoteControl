# RemoteControl — 用手机远程控制你的 Windows 电脑

> 一个轻量级 **Android → Windows** 远程控制方案：手机是遥控器，Windows 上跑一个零依赖的 Node.js 服务端。通过安全的 **WebSocket 长连接** 通信——不需要桌面程序、不需要额外运行时（只要有 Node）。

## 🔒 零凭证安全模型

**APK 里完全不含任何凭证**——没有密码、密钥、Token。即使 APK 被逆向，也什么都提取不到。

- **设备指纹**：`AndroidID + Build.FINGERPRINT` 的哈希形成匿名、稳定的序列号。
- **服务端白名单**：只有 `whitelist.json` 中（`allow:true`）的序列号能连接。未授权设备直接断开。
- **授权流程**：新设备进入 "pending" 待授权，直到管理员在服务端控制台输入 `允许 <序列号>`。
- **即时生效**：服务端每次连接都重读白名单——授权后无需重启服务。

## 🧱 架构

```
┌───────────┐        wss (TLS，可用 cloudflared/frp 转发)      ┌──────────────┐
│ Android APK│  ────────────────────────────────────────────▶ │ Windows 服务端│
│  (控制器,    │        WebSocket 长连接                        │    (Node.js)   │
│  零凭证)     │                                              │ control_server│
└───────────┘                                                │     .js        │
      ▲                                                       │ 设备鉴权+白名单 │
      └──────────── 指令 / 屏幕帧 ──────────────────────────▶   │ 进程/系统/文件 │
                                                              │ 推送告警       │
                                                              │ 关机/重启      │
                                                              └──────────────┘
```

- **协议**：扁平 JSON 消息（每条可选带 `seq`，响应回显）。
- **屏幕**：常驻 PowerShell 进程用 `System.Drawing` 抓屏，发送**二进制帧**（`SCRN\x01` 魔数头 + JPEG）给观看端。零第三方依赖。
- **推送 (v2.0)**：`rc_push.js` 跑监控循环（CPU 阈值 / 进程消失 / 定时任务），通过同一 WebSocket 把告警推给手机。

## 🚀 快速开始（Windows 服务端，一条命令）

> 需要 **Windows** + **Node.js 18+**（LTS）。服务端除 `ws` 外零依赖——普通/后台运行无需管理员。

```powershell
cd scripts
.\deploy.ps1                 # 默认：端口 8899，后台运行
.\deploy.ps1 -Port 9000      # 自定义端口
.\deploy.ps1 -Service on     # 注册为 Windows 服务（需 nssm + 管理员）
.\deploy.ps1 -Uninstall      # 停止并卸载服务
```

脚本自动检查 Node、安装依赖、生成空白 `whitelist.json`、启动服务端。

### 授权你的手机

1. 打开 APK，填写服务器地址，点 **连接**。
2. App 显示"待授权"，并显示它的**序列号**。
3. 在服务端控制台（或用 `授权设备.ps1`）输入 `允许 <序列号>`。
4. 重新连接——现在已授权。

## 📱 Android App（v2.0）

- **设置界面**（右上角 ⚙）：主题配色、记住服务器开关、通知权限、后台服务、各告警开关（总开关 / CPU / 进程）。
- **定时关机**：电源卡片 → "定时关机" → 选一个每天的时间（`HH:MM`）或取消。
- **后台常驻**：前台服务保持连接与告警在后台存活；可在设置里关闭（ACTION_STOP）。
