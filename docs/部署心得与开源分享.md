# 我闲得慌，给自己写了个"手机遥控电脑"的玩意，开源了

电脑搁家里，人经常不在跟前。有时候就想看看它是不是还活着，进程有没有抽风，实在不行远程给它关个机。

市面上的远程控制软件我装过，功能是猛，但每次打开都要登录，还要忍受各种广告弹窗，慢，还重。我寻思就这点需求，犯得着为它掏钱包、被广告糊脸吗？

算了，自己写一个吧。

## 大概是个什么东西

手机装个 App，电脑跑个 Node 小服务，俩走 WebSocket 长连接。手机是遥控器，电脑是被控的。

能干啥：
- 看进程、搜进程、强杀进程
- 远程关机、重启
- 看系统信息（CPU、内存、磁盘、开机多久了）
- 翻文件，进目录那种
- 实时看桌面画面（只能看，不许动，免得哪天手贱点到不该点的）

做的时候我特意砍掉了一些功能：远程操作鼠标键盘、剪贴板、锁屏，这些一概不要。能做，但不做，少一个功能就少一堆幺蛾子。

## 最让我得意的是这个安全设计

远程控制这东西，牵扯到"控制别人电脑"，安全上我不敢含糊。

最核心的一点：**APK 里一个密码、一个密钥都不放**。就算有人把我 App 反编译了，翻个底朝天，也翻不出任何能用的凭据。因为从根本上就没有。

那怎么认设备？用手机的一个硬件指纹（AndroidID + 设备型号哈希）生成一串编号。服务端有个白名单，只有名单里的编号才放行。新手机第一次连，会停在"待授权"，我在电脑上点一下确认才放进去。

这套叫"零凭据 + 白名单指纹"。我特别想让人知道这个思路——尤其对反编译那帮人，直接免疫，没得打。

## 踩坑记录，都是真金白银换的

肯定不能一帆风顺，说几个印象深的。

**内网穿透。** 电脑在家里，手机在外面要连，就得有公网。我不想花钱买服务器、不想备案，最后用了 cloudflared 隧道。免费，不用开端口，还白送 TLS，连上去直接就是 wss://，加密的。这波白嫖我很满意。

**Windows PowerShell 的中文乱码，差点把我搞崩溃。** 让服务端调 PowerShell 取系统信息，Windows 自带那个 PowerShell 5.1，中文脚本要是没带 BOM 头，它直接给你读成乱码，跑出来全是一堆"锟斤拷"。我一开始内联传参数，各种引号、$ 符号转义，调了一下午没调对。最后学乖了：所有脚本写成独立 .ps1 文件，强制加 BOM，参数用文件传而不是命令行拼。从那以后省心多了。

**Android 构建环境从零搭，也挺折磨。** 一台干净的 Windows，要编译得装 JDK、Android SDK、Gradle。中间还遇到 AGP 不给在中文路径下编译——就是说我文件夹名字是中文它都嫌弃，得加个 override 参数才放行。还有签名用的 keystore，丢了你以后就别想升级了，我单独给它做了备份，这玩意儿真丢了能哭一宿。

**一个特别迷惑的 bug。** App 老报"获取进程失败"，可我这边服务端明明返回数据了。查半天，原来是服务端成功时只回 `{processes:[...]}`，压根没有 `ok` 字段；但 App 那边是按"有没有 ok=true"判断成功，两边对不上，就一直误判。这种前后端字段约定的坑，真能让你查半宿。

**转屏断连。** 用户跟我说"转个屏幕就断了"。查来查去，根子在主界面的 onDestroy 里误调了全局连接的 disconnect()，一离开页面、一转屏，唯一的连接就被掐了。最后三管齐下：主界面锁竖屏、退出页面只清监听不掐连接、再加个断线 5 秒自动重连。这才稳住。

## 关于开源，我认真纠结过

项目做完，觉得放着可惜，想开源。

先说许可证。我一开始想用 AGPL，后来琢磨明白了：我这个是手机直连自己电脑，根本不是对外提供网络服务，AGPL 那条"通过网络服务也算发布"的条款对我压根没意义，用普通的 GPL-3.0 就够了，也更名副其实。

然后我又不想被人拿去卖钱。所以在 GPL 基础上加了条非商用条款：**免费给大家用，随便改随便研究，但谁敢拿去搞商业用途，得先跟我说一声、拿我书面授权才行。**

我还特意在条款里写明白：**开源给公众用 ≠ 商用**。我开源是开放分享，但版权和商用权都还在我手里。有人想拿去做收费软件，不好意思，得先过我这一关。

> 顺便说，开源前最该检查的不是代码，是 .gitignore。签名 keystore 要是传上去被人下载，人家就能伪造你的 App 更新包，等于全套家当给人了。我发之前专门跑了个命令确认密钥没混进提交里，这个多花一分钟，能省一辈子的心。

## 现状

东西已经挂 GitHub 上了：
- 仓库：github.com/YANYIyes/RemoteControl
- Release v1.2 里有现成的 APK，下载就能装
- Windows 端一条命令部署，手机装 App 填个地址就能连

写这玩意的最大感触就三点：

一是**小项目也能搞得挺正经**，不用为了显得厉害硬堆技术，把一件事做干净、做安全、真能解决问题，比啥都强。

二是**安全是设计出来的，不是堆出来的**。零凭据这个设计，让我这套东西在反编译面前没啥可偷的。

三是**踩坑是真的涨记性**。上面那些坑，每个背后都是一条能写下来的教训，下次再也不犯。

你要是对远程控制、Android、WebSocket、开源许可证哪个感兴趣，仓库可以 star 一下。有想法也欢迎提 Issue，我这个人挺好说话。

---
想用的话：
1. 手机下载 `远程控制-v1.2-release.apk` 装上
2. 电脑跑 `scripts\deploy.ps1` 一条命令部署
3. App 填地址：局域网 `ws://电脑IP:8899`，公网 `wss://你的域名`
4. 连上后在电脑执行 `auth.ps1 allow <序列号>` 授权，完事。

顺手点个 star 呗，写这个可费了不少头发。
